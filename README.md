FLORAFLOW - Sistema de floricultura (Flask + SQLite)

COMO EXECUTAR
1) Criar a venv:        python -m venv venv        (Mac: python3 -m venv venv)
2) Ativar a venv:       venv\Scripts\activate      (Mac: source venv/bin/activate)
3) Instalar o Flask:    pip install -r requirements.txt
4) Criar o banco:       flask init-db --dados
5) Ligar o site:        python app.py
6) Abrir no navegador:  http://127.0.0.1:5000
